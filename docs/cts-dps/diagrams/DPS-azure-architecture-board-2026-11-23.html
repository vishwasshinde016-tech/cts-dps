Page 4 · How pages are chosen: for the rules, and for the AI

The code chooses the pages, never the AI. The rules read every page; the AI reads only selected pages, in batches that fit one prompt.

Rules (no AI)
Which pagesEvery page of the page model. skills/covenants/rules.py:84
Safety netEvery sentence with a duty word (shall, must, will not ...) becomes a ledger candidate, so nothing is missed. skills/covenants/pages.py:61 skills/covenants/ledger.py:168
StatementsLong reports: the best balance sheet, P&L and cash-flow pages are scored and read first; summary / ratio pages are skipped. extraction/statement_pages.py:173
Unreadable pagesPages below quality 0.3 are not trusted for any value; listed as UNREADABLE_PAGES. skills/runner.py:43
AI · covenants pack (agreements)
Priority1 RULES pages (where the rules found something) → 2 SECTION (covenant headings and the next page) → 3 DUTY pages (most duty sentences first) → 4 DEFINITIONS (the 2 best definition pages). skills/covenants/pages.py:98
LimitsFrom pack.yaml: {max_pages: 25, rules: covenant_section, max_batches: 12, same_batch_for_parts: true, parts: [financial, undertakings, reporting, events_of_default]}; prompt ≤ 60,000 characters (MAX_PROMPT_CHARS). skills/common.py:15
4 focused partsfinancial · undertakings · reporting · events_of_default: each part reads each batch with its own task and taxonomy slice. skills/covenants/parts.py:75
Not sentPages that fit no batch are listed (PAGES_NOT_SENT); the agent can still open any page with page_text / search_text.
